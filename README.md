# 🛒 MALKANTHI STORES — Grocery Billing System

A desktop-based Grocery Billing and Inventory Management System developed using Python, Tkinter, and SQLite.

This application is designed to simplify everyday grocery store operations, including billing, inventory management, customer credit tracking, supplier management, and business reporting.

## ✨ Features

- Product and inventory management
- Barcode scanner support
- Weight-based billing (kg/g)
- Cash, card, and bank transfer payments
- Customer management and credit sales
- Customer credit payments and statements
- Supplier management and purchase orders
- Stock adjustments and inventory alerts
- Product categories
- Expiry date alerts
- Cashier login and shift management
- Sales and profit dashboard
- Daily cash register
- Receipt generation
- Business reports and exports
- Database backup and restore

## 🛠 Technologies Used

- **Python** — Application logic
- **Tkinter** — Desktop user interface
- **SQLite** — Local database
- **OpenPyXL** — Excel reports
- **Windows** — Target operating system

## 🚀 Installation

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal inside the project folder.
4. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

5. Run the application:

```bash
python grocery_billing_system_v10.py
```

On Windows, the `py` command may also be used.
